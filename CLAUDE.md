## Design Context

Este proyecto tiene contexto de diseño capturado por el skill `impeccable`:

- **PRODUCT.md** — registro `product`, plataforma `web`. Herramienta interna
  de soporte técnico/TI de INIA (equipos, impresoras, VPN, WiFi, licencias,
  correos, usuarios de red, auditoría). Usuarios: personal de mesa de
  soporte/TI (roles ADMIN/SOPORTE). Éxito = menos tiempo buscando
  información, trazabilidad/auditoría real, menos errores operativos.
- **DESIGN.md** — sistema visual "Panel Operativo INIA": verde institucional
  (#63a431) como único color de acción/marca, ámbar de acento (#fab50b)
  puntual, colores de módulo como acento (nunca fondo completo), sombras
  ambientales sutiles, DM Sans única familia tipográfica, paridad completa
  claro/oscuro.

Antes de diseñar o tocar UI, lee ambos archivos en la raíz del proyecto.
