## Design Context

Este proyecto tiene contexto de diseño documentado en:

- **PRODUCT.md** — propósito, usuarios y principios operativos del sistema.
- **DESIGN.md** — sistema visual “Social Utility · Liquid Glass”: azul marino,
  negro azulado y blanco; colores de acción sólidos; superficies de vidrio
  controladas; Manrope Variable; Tabler Icons; paridad completa claro/oscuro.

Antes de diseñar o tocar UI, lee ambos archivos en la raíz del proyecto.
